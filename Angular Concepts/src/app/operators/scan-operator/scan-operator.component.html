Syntax

  

  
scan()

  
Applies an accumulator function over the source Observable and emits EACH intermediate accumulated value. Like Array.reduce(), but the result is a stream, not a single final value.

  
Analogy: Like a running scoreboard — it doesn't wait for the game to end. Every basket updates the score in real time.
