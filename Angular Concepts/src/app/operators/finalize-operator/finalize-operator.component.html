Syntax

  

  
finalize()

  
Calls a function when the Observable terminates — whether by complete(), error(), or unsubscribe(). Like a finally block in try-catch. Use it to hide loading spinners, release resources, or log cleanup.

  
Analogy: Like a restaurant closing time — doesn't matter if the night was good or bad, the chairs go up and lights go off regardless.


  

    
Live Demo

    
Notice that finalize() fires in both the success and error cases — it's guaranteed cleanup.
