Syntax

  

  
throttleTime()

  
Emits the FIRST value from the source, then ignores all subsequent emissions for N milliseconds, then emits the first value after the silence window ends.

  
Analogy: Like a smoke alarm that sounds the first time, then silences for 1 minute before it can ring again — prevents alarm fatigue.


  

    
throttleTime(1000) — emits FIRST value, ignores rest for 1s

    
vs

    
debounceTime(1000) — ignores all, emits LAST after 1s pause
