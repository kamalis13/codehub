Syntax

  

  
startWith()

  
Emits specified values BEFORE the source Observable starts emitting. Useful for providing an initial loading state, default value, or seed value for scan().

  
Analogy: Like a "Welcome" message that plays before a movie starts — the main content hasn't begun yet but something meaningful shows immediately.
