Syntax — Angular HTTP caching pattern

  

  
shareReplay()

  
Multicasts the source Observable, replays the last N values to new subscribers, and caches the result. This is the standard Angular pattern for sharing HTTP calls across multiple components — so the request fires only once.

  
Analogy: Like a conference call recording — instead of briefing each person separately, you record it once and play it back to anyone who asks.
