Syntax

  

  
exhaustMap()

  
Projects each source emission to an inner Observable, but IGNORES new source emissions while the inner Observable is still active. The 4th flattening operator — the "bouncer" of the family.

  
Analogy: Like a bouncer at a door — while one person is inside being processed, new arrivals are turned away until the current person is done.


  

    
mergeMap
Runs ALL concurrently

    
switchMap
Cancels previous, uses latest

    
concatMap
Queues all, runs in order

    
exhaustMap
Ignores new while busy
