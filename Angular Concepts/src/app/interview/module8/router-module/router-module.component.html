Module 8 — Routing

RouterModule

Enabling navigation between views in a single-page application

📌 Definition

RouterModule is Angular's built-in module that provides the complete client-side routing infrastructure — the Router service, RouterOutlet directive, RouterLink directive, and ActivatedRoute service. In standalone apps, provideRouter() provides the same capabilities without an NgModule wrapper.

🤔 Why is it needed?

  • Enable single-page application navigation without full page reloads
  • Map URL paths to specific components
  • Maintain browser history (back/forward buttons)
  • Support deep linking (bookmarkable URLs)
  • Enable lazy loading of feature modules for performance

⚙️ Internal Working

    
RouterModule.forRoot() (or provideRouter()) registers the Router service in the root injector and configures it with the provided Routes array. When the URL changes (via navigation, browser back/forward, or direct entry), the Router matches the URL against the Routes array in order, finds the first match, and renders the matched component inside the nearest router-outlet. Route guards and resolvers run before the component is rendered.

❌ Disadvantages

      
    
        
  • Initial configuration can be verbose for large apps
    • 
        
  • Multiple router-outlets (auxiliary routes) are complex to manage
    • 
        
  • Route debugging requires familiarity with Router events
    • 
        
  • forRoot/forChild confusion in multi-module apps
    • 
      

    

  


  

    
🏆 Best Practices

    
    
      
  • Define routes in a dedicated app.routes.ts file
    • 
      
  • Use provideRouter() in standalone apps
    • 
      
  • Apply routerLinkActiveOptions exact:true on home/root links
    • 
      
  • Use withPreloading(PreloadAllModules) for better UX
    • 
      
  • Use withComponentInputBinding() to simplify route data access
    • 
    

  


  

    
⚠️ Common Mistakes

    
    
      
  • Calling RouterModule.forRoot() in multiple modules (causes router re-initialization)
    • 
      
  • Forgetting router-outlet in the template
    • 
      
  • Using href instead of routerLink (triggers full page reload)
    • 
      
  • Not exporting RouterModule from a shared module
    •
