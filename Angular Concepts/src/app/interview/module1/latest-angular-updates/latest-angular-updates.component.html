💾 Angular 17 — New Control Flow Syntax

Angular 17 replaced structural directives (*ngIf, *ngFor, ngSwitch) with a new built-in control flow syntax. The new syntax is compiled directly by the Angular template compiler — no need to import CommonModule. @for requires a track expression (enforcing performance best practices), and @empty handles empty collections without extra ngIf wrappers. 


  


  

    
⏳ Angular 17 — @defer (Declarative Lazy Loading)

    

      @defer lets you declaratively code-split and lazy-load parts of your template.
      The content inside the block is bundled separately and only loaded when the trigger fires.
      It supports @placeholder (shown before loading), @loading
      (shown during loading), and @error blocks. This eliminates complex IntersectionObserver
      code or route-level lazy loading just to delay a single widget.
    

    

  


  
  

    
💡 Angular 18 — Zoneless & Key Features

    

      Angular 18 introduced experimental zoneless change detection, removing the Zone.js
      dependency. Change detection becomes signal-driven — Angular only updates components whose signals
      changed. Also notable: ng-content fallback (default projected content when nothing
      is provided), Material 3 stable, and route-level SSR render modes
      (prerender, server-render, or client-render per route).
    

    

  


  
  

    
🔥 Angular 19 — Signal-Based Component APIs

    

      Angular 19 completed the signal-based component API surface. input() creates
      a signal-typed @Input. output() replaces @Output + EventEmitter.
      model() creates a two-way bindable signal (replaces the @Input + @Output(xChange)
      pair). viewChild() and contentChild() return signals that automatically
      reflect the current DOM state without needing ngAfterViewInit.
      linkedSignal() creates a derived but manually-settable signal.
    

    

  


  

    
🌊 Angular 19 — Incremental Hydration & Resource API

    

      Incremental hydration lets SSR pages hydrate in chunks instead of all at once.
      Sections marked with @defer (hydrate on viewport) only load their JS bundle
      when the user scrolls to them. The Resource API is a signal-based data-fetching
      primitive: it ties an HTTP request to a signal (the request parameters), and re-fetches
      automatically when parameters change — no manual subscribe/unsubscribe.
    

    

  


  
  

    
🌟 Angular 20 — Stable APIs & Polish

    

      Angular 20 (May 2025) graduates several experimental features to stable:
      zoneless change detection (now provideZonelessChangeDetection()),
      httpResource() for signal-based HTTP, and further improvements to SSR hydration
      performance and tree-shaking. TypeScript 5.8 is supported.
