Core Concept

AsyncSubject

Only emits the LAST value, and only when complete() is called

📦
AsyncSubject — acts like a Promise. It collects all values pushed to it, but only delivers the very last one to subscribers — and only when complete() is called.
💡
Use it when you have a stream that eventually produces one final result, and you don't care about intermediate values.
