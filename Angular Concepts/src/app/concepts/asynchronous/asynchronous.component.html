🔢 Concept 2

Asynchronous

"Start a task and move on — handle the result when it arrives."

📖
Definition

Tasks run in the background. JavaScript doesn't wait — it continues running other code. When the background task finishes, it notifies you via a callback, Promise, or Observable.

🍽️
Real-life analogy

Ordering food at a restaurant. You order, then chat with friends. The waiter brings your food when it's ready — you didn't stand at the kitchen door waiting.

⚡
Most common async tasks in Angular

API calls · setTimeout · File reads · User clicks · WebSockets
