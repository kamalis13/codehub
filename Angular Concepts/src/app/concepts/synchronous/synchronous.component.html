🔢 Concept 1

Synchronous

"Do one thing at a time, in order — wait for each to finish."

📖
Definition

Tasks execute one after another. The next task only starts after the current one fully completes. The program blocks and waits.

🏧
Real-life analogy

An ATM queue — Person 1 finishes → Person 2 steps up. Nobody jumps ahead.

⚡
Key rule

Task A → Task B → Task C — always in this order, no surprises.
