Angular-Specific

The async Pipe

Angular's built-in template pipe that auto-subscribes and auto-unsubscribes to Observables

🔌
async pipe — Angular template pipe written as | async. It subscribes to an Observable when the component is created, displays the latest value, and automatically unsubscribes when the component is destroyed. No ngOnDestroy needed.
🛡️
Why use it? Manual subscriptions require you to unsubscribe in ngOnDestroy. Forgetting causes memory leaks. The async pipe handles this for you automatically.
