Core Concept

ReplaySubject

Buffers the last N values and replays them to any new subscriber

📼
ReplaySubject — like a DVR. It records the last N emissions and plays them back to any new subscriber instantly, even if those values were pushed before the subscription.
💡
Key difference from Subject — a regular Subject only forwards future values. A ReplaySubject(2) stores the last 2 and replays them to latecomers.
Subject
No memory. Late = miss all past.
ReplaySubject(N)
Replays last N values to new subscribers.
BehaviorSubject
ReplaySubject(1) with mandatory initial value.
AsyncSubject
Only emits the LAST value on complete().
