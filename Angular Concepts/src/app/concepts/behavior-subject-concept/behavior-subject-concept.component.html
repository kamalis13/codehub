🔢 Concept 8

BehaviorSubject

"Like Subject but with memory — late subscribers instantly receive the current value."

Subject (no memory)
next(1)
next(2)
← subscriber joins here
next(3)
Late sub receives: only 3 ❌ (missed 1 and 2)
BehaviorSubject (remembers last)
next(1)
next(2)
← subscriber joins here
replays: 2 ✅
next(3)
Late sub receives: 2 (immediate) then 3 ✅
📖
Definition

A BehaviorSubject is a Subject that always stores the latest emitted value and gives it to any new subscriber immediately upon subscription. It requires an initial value.

📋
Analogy

A scoreboard — it always shows the current score. Walk in late and you immediately see the current state, not a blank board.

🏗️
Angular use case

Perfect for shared state — current logged-in user, selected theme, cart item count. Any component can subscribe and immediately get the current state.
